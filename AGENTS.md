# CASTOFF COLOSSUS

Standalone original 2.5D mech action platformer. Never edit PROMPTRON, original cartridges or completed sibling games. Read docs/CONTRACT.md before implementation.
Root owns design, integration, artwork, verification, Git and release. Workers own explicit files only, are not alone, must preserve others' edits, cannot spawn descendants, commit, push, build or run visible browsers unless explicitly delegated.
Only public kkp8121-rgb repositories. Each push requires separate approval. Stage explicit paths; never output or commit credentials.
No visible browser. Headless Playwright permitted. Bundle a classic offline IIFE using relative local assets, including file:// and Pages subpaths.
Inspection returns copies only. Full play uses real inputs and records the bundle hash; isolated fixtures are labelled separately.
Responsive selectors must match actual DOM. Verify visible controls and center hit testing at 390x844 and 844x390. Pause/guide/back preserves suspended audio. Gameplay never consumes menu clicks or stale held inputs.
Use apply_patch for Korean. Preserve original art. Models must be grounded and articulate at their real joints; render geometry must agree with collision coordinates. Opaque meshes cast hardware shadows, transparent effects do not.
After guarded transitions, change UI only when core status permits it. Register documented event listeners, drain events once, and avoid rebuilding geometry every frame.
