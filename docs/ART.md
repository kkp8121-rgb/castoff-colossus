# Original artwork

Root uses the built-in ImageGen tool for original raster artwork. No existing franchise characters, logos or external runtime assets are used. Rhea is an original adult pilot, age 31. Original PNG is retained in `art-source/`; WebP conversion changes format only. The game's articulated meshes are authored directly in Three.js.

The original landscape PNG is 1536×1024. `assets/key-art.webp` is a format-only quality-88 conversion (272,810 bytes). All playable geometry, the sky gradient and instanced factory buildings are code-authored; the painting is the title artwork. No generated text or external franchise assets are used.
